Daily Technical Snippet

GraphRAG — retrieval over a knowledge graph, not a pile of chunks

Plain RAG chops documents into chunks and retrieves the top-k by vector similarity — great for “find the passage that answers this”, weak at questions that need to connect facts scattered across many documents. GraphRAG first uses an LLM to extract entities and relationships into a knowledge graph, clusters it into communities and summarises each; at query time it retrieves over that structure — traversing edges and community summaries — so it can answer global, multi-hop questions a chunk-similarity search never reaches. Think "how are these two entities related?", not just "where is X mentioned?"

Learn more

The trade-off is cost and freshness: building the graph is an expensive up-front LLM pass, and it goes stale as source data changes, so you re-extract or update incrementally. Microsoft's open-source GraphRAG popularised the pattern, and hybrids now blend graph traversal with vector search (local vs global search modes). For Kepler the read is that a graph is just structured memory — and the questions “which entity, which relationship, extracted when, from what source” are exactly the provenance a user-owned, auditable store should answer out loud, not bury inside an opaque index.

Top Story · AI & Agents

The payment rails for autonomous agents just went live — Visa, Mastercard, Stripe and Google line up behind the x402 open standard

This is the week agents got a way to pay. The x402 Foundation — 40 members including Visa, Mastercard, Amex, Stripe, Adyen, Shopify, Google, AWS and Cloudflare — is standardising machine-to-machine payments over plain HTTP, reviving the long-dormant “402 Payment Required” code so an agent can settle a transaction mid-request. On 24 July, Sunrate and Mastercard published a white paper mapping 13 high-value agent payment use cases across B2B; forecasters now peg consumer agent spending tripling to ~US$3.35T by 2030. Agents can now transact — the open question is what they remember about it.
