Daily Technical Snippet

Corrective RAG (CRAG) — grade the retrieval before you trust it

Plain RAG retrieves the top-k chunks and feeds them straight to the model — which quietly hallucinates when the retrieval is thin or off-topic, because nothing ever checks whether the evidence was any good. Corrective RAG inserts a lightweight retrieval evaluator that scores each retrieved document as correct, incorrect or ambiguous. On correct it refines and keeps the passages; on incorrect it discards them and falls back to a broader source (often web search); on ambiguous it does both. The point is a confidence signal attached to every answer — the system knows, and records, how sure it was.

Learn more

CRAG is decoder-agnostic — it bolts onto any existing RAG pipeline as a pre-generation gate — and it pairs naturally with a rewrite-then-retry loop when confidence is low. The wider shift it belongs to is treating retrieval quality as first-class, inspectable metadata rather than an invisible internal step. For Kepler that is the whole thesis in miniature: a memory a user owns shouldn't just return context, it should be able to say which source, graded how confident, retrieved when — the provenance an auditable store surfaces out loud instead of burying inside an opaque index.

China's first binding AI-agent rules are in force — three tiers of decision authority and mandatory audit trails

The world's first regulatory framework treating AI agents as a distinct technology took effect on 15 July and enterprises are scrambling to comply. Agents are sorted into three tiers — autonomous for routine tasks, recommend-then-approve for material decisions, escalate-to-human for high-stakes calls — and every deployer must document each agent's tier and maintain audit trails. It binds anyone touching Chinese users or data, physical presence not required.
