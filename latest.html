Daily Technical Snippet

Parent-document retrieval — search on small chunks, return the big context

Search wants small chunks and generation wants big ones — and parent-document retrieval refuses to pick. You embed and index tight child chunks (a sentence or two) so the vector match is sharp and unambiguous, but at fetch time you hand the model back the larger parent passage each match belongs to — so it reads a whole coherent section, not the stranded fragment the search actually hit. Precision on the way in, context on the way out, without bloating the index with giant vectors.

Learn more

The cost is bookkeeping: you keep a child → parent map and dedupe when several children point at the same parent, so one strong section can't flood the context window. Teams often stack it with reranking — retrieve wide on children, collapse to parents, then rerank the parents. For Kepler the shape is the idea: a user's memory should be addressable at fine grain but readable as coherent context — recall the exact fact, return the passage a person could actually verify, and keep the link between the two intact.

Top Story · AI & Agents

MCP goes stateless: the 2026-07-28 spec ships — the agent protocol Kepler rides just became web-scale infrastructure

On 28 July the Model Context Protocol shipped its biggest revision since remote MCP launched, and the headline is a stateless protocol core: the initialize handshake and Mcp-Session-Id are retired, so every request is self-describing and any request can hit any server instance behind a plain round-robin load balancer — no sticky sessions, no shared session store. It also brings cacheable tool/list results, header-based routing (Mcp-Method/Mcp-Name), Multi Round-Trip Requests for mid-call elicitation, OAuth hardening, and a formal extensions framework (Tasks, MCP Apps, Enterprise-Managed Auth). All four Tier-1 SDKs ship same-day; TypeScript and Python have each crossed 1B downloads. AWS, Google Cloud, Microsoft Foundry and Cloudflare are on it day-zero.
