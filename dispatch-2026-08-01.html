Daily Technical Snippet

Stateless protocols — why an agent's memory has to live outside the connection

A stateful protocol keeps a live session: the server remembers who you are, what you've said and where you are in the exchange, all held inside the open connection. Convenient — until you want to scale, because every request has to return to the exact machine holding that session. A stateless design flips it: each request carries its own identity and context, so it can land on any server behind a load balancer, and nothing is remembered between calls. That's exactly the move MCP just made in its 2026-07-28 spec — dropping the initialize handshake and session IDs for a request/response core that scales on serverless infrastructure.

Learn more

The catch is in the name: if the protocol remembers nothing, then any memory the agent needs — who the user is, what happened yesterday, why it made a call — must be persisted elsewhere and fetched by reference on each request. Statelessness doesn't remove the need for memory; it relocates it, out of the connection and into an addressable layer the request can point at. For Kepler that's the whole thesis handed over by an infrastructure decision: a URL-first, user-owned memory the agent looks up per call is the natural home for exactly the state a stateless protocol now deliberately refuses to hold.

Top Story · AI & Agents

MCP goes stateless: the 2026-07-28 spec rebuilds the agent protocol for enterprise scale — and quietly relocates memory out of the connection

On 28 July the Model Context Protocol shipped its largest revision yet, replacing the bidirectional stateful design with a request/response stateless core. Gone are the initialize/initialized handshake and session IDs; each request now carries its own version, identity and capabilities, so it can land on any server behind a load balancer — unlocking serverless, horizontally-scaled agent deployments. New machinery (multi-round-trip requests, header-based routing, cacheable lists, RFC 9207 auth hardening) rounds it out. MCP is now near half a billion SDK downloads a month, with TypeScript and Python each past a billion total.
